# Api‑React‑Medio

Uma aplicação React / Vite para buscar espécies (animais, fungos, etc) usando uma API de serviço externo (como o iNaturalist).

## 🧪 Funcionalidades

- Campo de busca para digitar o nome científico ou comum de uma espécie  
- Busca de dados taxonômicos (classe, família, ordem, nome científico) via API  
- Exibição dos resultados numa `SpeciesCard` com informações relevantes  
- Feedback de carregamento (“Carregando...”) e tratamento de erro  

## 📂 Tecnologias

- React (hooks)  
- Vite (build rápido)  
- Tailwind CSS (estilização)  
- iNaturalist e wikipedia (de API) para buscar dados de espécies
